# ODU Labs and Coursework Projects

This folder is reserved for Old Dominion University cybersecurity and networking labs that are documented as part of my ongoing learning.

## Purpose
This section keeps all ODU lab work organized and easy to navigate for recruiters, instructors, and future employers.

## Planned Structure
Each lab/project should be added as a separate folder with:
- A descriptive name
- A README file
- Screenshots or evidence
- Notes and observations

## Example Naming Convention
- `wireshark-network-analysis`
- `nmap-network-discovery`
- `linux-security-basics`
- `windows-networking-lab`
- `networking-fundamentals-lab`

## Documentation Standards
Every ODU lab entry should include:
- Project Overview
- Objectives
- Tools Used
- Technologies
- Skills Demonstrated
- Methodology / Steps
- Results
- Screenshots / Evidence
- What I Learned
