# Linux Storage Management and Disk Partitioning Using Command Line Tools

## Project Overview
This project focused on Linux storage management using command-line tools to create disk partitions, format filesystems, and mount and unmount storage devices. It was designed to demonstrate how Linux systems organize, manage, and access storage resources. These skills are essential for system administration, troubleshooting, and maintaining reliable IT infrastructure.

## Methodology / Steps
1. Defined the task and learning objectives for working with Linux storage and system administration.
2. Set up the virtual lab environment and prepared the Linux system for testing.
3. Gathered system information using Linux commands to identify available disks and storage devices.
4. Used command line tools to add a virtual disk, create partitions, and format the new partition with the ext4 filesystem.
5. Mounted the new filesystem and verified that the /cyse directory was accessible.
6. Documented command outputs, screenshots, and observations throughout each step.
Unmounted the filesystem and verified that the /cyse directory no longer contained mounted files or directories.
## Results
- Identified the newly added virtual disk as /dev/sdb.
- Observed the creation of the /dev/sdb1 primary partition.
- Confirmed the successful creation of the ext4 filesystem.
- Verified that the filesystem could be mounted and unmounted successfully.
- Confirmed that the /cyse directory was empty after unmounting.
