38| ## Methodology / Steps
39| 1. Defined the task and learning objectives for working with Linux storage and system administration.
40| 2. Set up the virtual lab environment and prepared the Linux system for testing.
41| 3. Gathered system information using Linux commands to identify available disks and storage devices.
42| 4. Used command line tools to add a virtual disk, create partitions, and format the new partition with the ext4 filesystem.
43| 5. Mounted the new filesystem and verified that the /cyse directory was accessible.
44| 6. Documented command outputs, screenshots, and observations throughout each step.
45| Unmounted the filesystem and verified that the /cyse directory no longer contained mounted files or directories.
